# WIS 直播数据中心

面向直播中心的只读经营看板。优先读取 Fandow MCP 数据，场次为空时回退到已配置的飞书根数据表。

## 数据口径

- 未返回、未映射或公式错误的数据保留为 null，界面显示“待核验”，不得当作 0。
- GMV、千川消耗、退款、观看、转化和在线人数分别记录可用性；聚合卡片展示已核验场次数。
- 小时趋势只绘制 GMV、ROI、转化率三项均有效的时段。
- 视频号渠道仅有日汇总 GMV 时，其余指标保持“待核验”。

## 验证

依次执行 npm.cmd ci 和 npm.cmd test。

生产入口由直播中心工作台反向代理提供；源数据凭据只存在服务端环境变量中。
