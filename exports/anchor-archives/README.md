# 主播档案本地归档版

入口文件：`recruitment-dashboard.html`

双击入口文件即可在浏览器中打开。页面不需要服务器，也不会自动连接飞书、MCP 或其他线上数据源。

## 文件清单

- `recruitment-dashboard.html`：页面结构、样式与交互逻辑。
- `assets/anchor-data.js`：截至 2026-08-14 10:00 的主播阵容、评分、排班、排名变化与复盘摘要。
- `assets/anchor-trends.js`：近 14 天趋势的排班核对、休息日、缺数断点与跨直播间记录。
- `index.html`：自动跳转入口。

该目录是静态快照，刷新页面只会重新加载当前文件内容。
