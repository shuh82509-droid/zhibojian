# 直播中心工作台

统一入口包含直播经营看板、主播全生命周期、飞书排班调度、协同中心和素材中心。

## 信息来源与状态

- 直播经营看板读取 MCP / 飞书根数据；未返回指标显示“待核验”，不按 0 处理。
- 调度中心读取飞书班表，并支持“预览差异—确认写回—写后回读—审计”链路。
- 协同中心的违规记录来自飞书群聊；账号、链接与异常 SOP 属于配置快照，已在界面显式区分。
- 招聘池、主播档案和素材页为随包交付的历史快照，不能代替实时业务台账。

## 安全边界

- 页面由 OA / 飞书登录门禁保护。
- 排班业务 API 还会向 WIS 品牌营销中枢复核 live-room-management 模块权限。
- 飞书应用凭据只存在服务端环境变量中；排班写入限定在既有日期块和既有时间段。
- SESSION_SECRET 必须不少于 32 个字符。

## 验证

调度中心：在 runtime/dispatch-center 运行 node --test schedule-api-server.test.js。

数据中心与协同中心：分别运行 npm.cmd ci 和 npm.cmd test。

生产发布使用候选容器验收；调度候选会以一个现有姓名执行同值写回，验证真实写权限、写后回读与审计，不改变可见排班内容。
